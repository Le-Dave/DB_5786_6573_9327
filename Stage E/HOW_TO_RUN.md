# הוראות כניסה והפעלה - מערכת ניהול מסעדה (שלב ה')

ממשק גרפי בשפת **Python** עם **customtkinter**, המתחבר לבסיס הנתונים המשולב ב-PostgreSQL.

## דרישות מקדימות

1. **Python 3.10+** מותקן.
2. **Docker** רץ, ובסיס הנתונים פעיל:
   ```bash
   docker compose up -d
   ```
   (הקונטיינר `PostgreSQL_DB` חייב להיות `Up`, מאזין על `localhost:5432`.)

## התקנת ספריות

מתוך התיקייה `Stage E/app`:
```bash
pip install -r requirements.txt
```
(מתקין `customtkinter` ו-`psycopg2-binary`.)

## הפעלת האפליקציה

```bash
cd "Stage E/app"
python main.py
```

## פרטי כניסה (Login)

חלון הכניסה נפתח עם פרטי בסיס הנתונים:

| שדה | ערך |
|---|---|
| Username | `MyUser` |
| Password | `password` |

לחיצה על **Login** מתחברת לבסיס הנתונים `DB5786David` ופותחת את המסך הראשי.
> הכניסה היא אימות אמיתי מול PostgreSQL - פרטים שגויים יחזירו שגיאת התחברות.

## שימוש במערכת

- **סרגל צד** (משמאל): 12 הטבלאות + הכלי **Queries & Programs**.
- **מסך טבלה (CRUD):**
  - הטבלה מוצגת ללא מזהים (ID), והמפתחות הזרים מוצגים כ**שמות** (לדוגמה קטגוריה במקום `category_id`).
  - **➕ Add** - הוספת רשומה (מפתחות זרים נבחרים מרשימה נפתחת של שמות).
  - **✏️ Edit** - בחירת שורה ולחיצה על Edit טוענת אוטומטית את שדות הרשומה (המשתמש מספק את המפתח, המערכת מביאה את היתר), ואז שומרים.
  - **🗑️ Delete** - מחיקת השורה הנבחרת.
  - **🔄 Refresh** - רענון הנתונים.
- **מסך Queries & Programs:**
  - 2 שאילתות משלב ב' (מנות שנוספו ב-2024 לפי קטגוריה; 5 הקטגוריות עם הכי הרבה קלוריות בממוצע).
  - פונקציות ופרוצדורות משלב ד': `fn_menu_item_kitchen_stats`, `fn_get_chef_preparations` (Ref Cursor), `sp_apply_category_price_increase`.

## מבנה הקוד

```
Stage E/app/
  main.py            - נקודת כניסה: מסך כניסה + לוח בקרה + ניווט
  db.py              - שכבת גישה לבסיס הנתונים (psycopg2)
  schema.py          - מטא-דאטה של 12 הטבלאות (עמודות, מפתחות, תצוגת שמות ל-FK)
  crud_view.py       - מסך CRUD גנרי לכל טבלה
  programs_view.py   - מסך הרצת שאילתות ותוכניות
  requirements.txt   - ספריות נדרשות
```
